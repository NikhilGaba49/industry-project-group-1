Define a function that extracts the row within the data that matches the suburb name given and drop the first column (which has all suburb names). Since docklands is missing most of the data before 2002Q1 (except 2000Q2), for simplicities sake, we will only look at data from 2002Q1 onwards. This is handled within our get_suburb() function.

# Define a function that extracts the row within the data that matches 
# the suburb name given and drop the first column (which has all suburb names).
get_suburb <- function(name) {
  y <- as.numeric(unlist(dt[dt$Suburb == name, -1]))
  Y <- ts(y, start = c(2000, 1), frequency = 4)
  
  # Docklands has no data before Mar 2002, so start it there
  if (name == "Docklands") {
    Y <- window(Y, start = c(2002, 1))
  }
  
  return(Y)
}

Deciding To Log Our Data

Here, we begin investigating whether or not we should log our data since this can make a large difference in our modelling process later on.

Firstly, we can make domain informed judgements as follows;

  1. House prices grow multiplicativley. Prices compound, as do the things that drive them: incomes, inflation and credit. A suburb growing at a steady 5% a year produces an exponential curve in levels but a straight line in logs. Linear trends therefore describe log prices much more naturally. A slope in logs is a constant percentage growth rate, which is how price growth actually behaves.

  2. Price changes scale with the price level. A $100 rise means something very different for a $300k house than for a $1.5m house in the context of rent. Market movements are proportional, so in dollar terms the volatility grows as prices rise. In levels, that makes the variance non-constant, which violates the constant-variance assumption behind ARIMA errors, AICc comparisons and prediction intervals. Logs turn proportional variation into roughly constant variation.

  3. Log differences are growth rates. diff(log(Y)) is approximately the quarterly percentage change, the same measure the ABS and industry indices use to report housing markets. This makes the model’s parameters and forecasts directly interpretable.

  4. It makes suburbs comparable. Our suburbs range widely in price. In levels, expensive suburbs dominate any cross-suburb comparison (RSS, AICc, weighting) simply because their numbers are larger. In logs, everything is on a percentage scale.

  5. Forecasts stay positive. Converting log forecasts back to dollars (exp()) can never produce a negative price, and the prediction intervals widen in proportion to the price level, which is realistic.

In this section, we will begin the modelling of the median rent prices for each suburb. Fixing A Trend Break

Define a function to represent the trend break indicator variable

trend_break <- function(b, time) {
  return ((time>b)*(time-b))
}

Now, upon qualitative analysis on the data, we decided to include a single trend break along with our time trend and stochastic component (to be modelled). So the following cell calculates, for each suburb, the most ideal location to have a trend break based off the residual sum of squares.

trend_breaks <- list()
# Find the optimal trend break 
for (s in dt$Suburb) {
  FirstForecast <- 2019.75
  
  Y  <- log(get_suburb(s))
  
  Time  <- time(Y)
  
  t_est   <- which(Time < FirstForecast)
  
  # We will have a standard 15% (3 years) zone where no break points are allowed.
  # So with the training set being from 2000Q1 to 2019Q3 gives:
  Break_range <- Time[which(Time >= 2003 & Time < 2016.75)]
    
  # M is a matrix for the RSS corresponding to each b
  M <- matrix(nrow = length(Break_range), ncol = 2)
  colnames(M) <- c("b", "RSS")
  M[, "b"] <- Break_range
  
  for (b in Break_range){
    TB_b <- trend_break(b, Time[t_est])
    X <- cbind(Time[t_est], TB_b)
    
    eq1 <- Arima(Y[t_est], order=c(0,0,0), xreg=X)
    
    # Store RSS in appropriate entry of M
    M[which(M[, "b"] == b), "RSS"] <-  sum(eq1$residuals^2)
  }
  b_best  <- M[which.min(M[, "RSS"]), "b"]
  
  trend_breaks[[s]] <- list(
    b_best  = b_best
  )
}

Fixing The Stochastic Part

Now its time to calculate the stochastic part of the equation. We will use ARIMA(p,d,q) to compute the stochastic components of our models.

We will now define a simulate_adf_cv() function that simulates many random walks (the unit-root null hypothesis) and, on each one, runs a Dickey–Fuller regression (no lagged differences) that includes the supplied deterministic terms \(X_{det}\): the trend and trend break at b when testing levels, or the level-shift dummy at b when testing first differences. It returns the simulated p-value, the share of simulated t-statistics below the observed t_stat, along with the simulated t-statistics themselves (tADF).

simulate_adf_cv <- function(n, X_det, t_stat, reps = 20000){
  t <- 2:n
  X <- X_det[t, , drop=FALSE]      # deterministic terms, aligned with t
  
  tADF <- matrix(nrow=reps, ncol=1)
  for (r in 1:reps){
    # Simulate under H0
    Y_simulated <- arima.sim(n=n, model=list(order=c(0,1,0)))[-1]
    
    DY <- Y_simulated[t]-Y_simulated[t-1]
    Y1 <- Y_simulated[t-1]
    
    tADF[r] <- summary(lm(DY~X+Y1))$coefficients["Y1","t value"]
  }
  
  p_val <- mean(tADF < t_stat)
  return(list(p_val = p_val, tADF = tADF))
}

Define a function adf_test() that runs a Dickey–Fuller regression of \(\Delta Y_t\) on the deterministic terms X_det and \(Y_{t-1}\), then compares the t-statistic on \(Y_{t-1}\) with the null distribution simulated by simulate_adf_cv(). It returns 1 if the unit root is not rejected at the 5% level (a difference is needed) and 0 if it is rejected (the series is stationary around the deterministic terms), so its output can be added directly to the differencing order d.

adf_test <- function(Y, X_det, reps = 20000){
  n <- length(Y)
  t <- 2:n
  
  Y_1 <- Y[t-1]
  DY  <- Y[t]-Y[t-1]
  X   <- X_det[t, , drop=FALSE]
  
  t_stat <- summary(lm(DY ~ X + Y_1))$coefficients["Y_1", "t value"]
  
  p_val <- simulate_adf_cv(n, X_det, t_stat, reps)$p_val
  return(1 * (p_val > 0.05))     # 1 = unit root (don't reject), 0 = stationary
}

Now, lets begin our model selection process for our ARIMA(p,d,q) models. For each suburb, this code takes log weekly rents from 2000 Q1 to 2019 Q3, tests for a unit root around the suburb’s trend break (and again in first differences if needed) to choose d, and then searches every ARIMA(p, d, q) with p, q ≤ 9, keeping the lowest-AICc model whose residuals pass the Ljung–Box test. It then forecasts 2019 Q4 to 2025 Q3, converts the forecasts back to dollars, and stores the model, its orders, the forecasts and the test-period RMSE.

NOTE: p and q were chosen (somewhat arbitrarily) as 9 to allow for 2 years of lags worth of data +1 to capture any yearly dependence but without becoming too computationally expensive.

fit_arima <- function(y, order, xreg, drift) {
  tryCatch(
    Arima(y, order = order, xreg = xreg, include.drift = drift),
    error = function(e) tryCatch(
      Arima(y, order = order, xreg = xreg, include.drift = drift, method = "ML"),
      error = function(e2) NULL
    )
  )
}
RNGkind("L'Ecuyer-CMRG")   # reproducible random streams across cores
set.seed(123)

fit_suburb <- function(s){
  pmax <- 9 # Max AR lag order
  qmax <- 9 # Max MA lag order
  FirstForecast <- 2019.75
  
  Y  <- log(get_suburb(s))
  
  Time   <- as.numeric(time(Y))
  t_est  <- which(Time < FirstForecast)
  t_test <- which(Time >= FirstForecast)
  
  b   <- trend_breaks[[s]]$b_best
  TBt <- 1 * (Time > b) * (Time-b)
  
  Y_test <- exp(Y[t_test])    # test data in dollars
  hmax <- length(t_test)
  
  # Storage for Ljung-Box p-values and AICc
  LBp <- matrix(nrow=pmax+1, ncol=qmax+1)
  rownames(LBp) <- paste0("p=", 0:pmax)
  colnames(LBp) <- paste0("q=", 0:qmax)
  AICc <- LBp
  
  nd <- adf_test(Y[t_est], cbind(Time[t_est], TBt[t_est]))
  
  if (nd == 1){
    # Drops first training quarter, so results line up with diff(Y[t_est])
    # which starts at the second quarter. 
    DU <- 1 * (Time[t_est][-1] > b)  
    nd <- nd + adf_test(diff(Y[t_est]), cbind(DU))
  }
  
  if (nd == 0){
    X <- cbind(Time, TBt)
    drift <- FALSE
  } else if (nd == 1){
    X <- cbind(TBt)
    drift <- TRUE      # drift = constant growth rate, replaces Time
  } else {
    X <- cbind(TBt)
    drift <- FALSE     # trend annihilated at d = 2
  }
  
  models <- list()
  
  for (p in 0:pmax){
    for (q in 0:qmax){
      eq <- fit_arima(Y[t_est], c(p, nd, q), X[t_est, , drop = FALSE], drift)
      
      if (is.null(eq)) next
      
      AICc[p+1, q+1] <- eq$aicc
      LBp[p+1,q+1] <- Box.test(eq$residuals, 
                             lag = max(8, p + q + 4), 
                             type = "Ljung-Box", 
                             fitdf = p + q)$p.value
      models[[paste(p, q)]] <- eq
    }
  }
  
  # Best model: lowest AICc among those passing Ljung-Box
  AICc_ok <- AICc
  AICc_ok[LBp <= 0.05 | is.na(LBp)] <- NA 
  
  if (all(is.na(AICc_ok))) return(NULL)   # no model passed Ljung-Box
  
  best <- which(AICc_ok == min(AICc_ok, na.rm = TRUE), arr.ind = TRUE)
  p_best <- best[1, 1] - 1
  q_best <- best[1, 2] - 1
  model  <- models[[paste(p_best, q_best)]]
  
  # Forecast the test period and convert back to dollars
  forecasts <- exp(forecast(model, xreg=X[t_test, , drop=FALSE], h=hmax)$mean)
  RMSE <- sqrt(mean((Y_test-forecasts)^2, na.rm = TRUE))
  
  return(list(
    suburb      = s,
    Y           = Y,
    Y_train     = Y[t_est],
    Y_test      = Y_test,
    model       = model,
    trend_break = b,
    nd          = nd,
    p           = p_best,
    q           = q_best, 
    AICc        = AICc,
    forecasts   = forecasts,
    RMSE        = RMSE
  ))
}

Lets define a function that will plot the appropriate trend lines and forecasts for a given suburb to help us visualize the forecasting performance and model fit.

plot_suburb <- function(s) {
  r <- results[[s]]
  
  Y      <- r$Y
  Time   <- as.numeric(time(Y))
  t_est  <- which(Time < 2019.75)
  t_test <- which(Time >= 2019.75)
  b      <- r$trend_break
  TBt    <- 1 * (Time > b) * (Time - b)
  
  if (r$nd == 0){
    X <- cbind(Time, TBt)
  } else {
    X <- cbind(TBt)
  }
  
  fc <- forecast(r$model, xreg = X[t_test, , drop = FALSE], h = length(t_test))

Fixing A Trend Break

trend_breaks <- list()
# Find the optimal trend break 
for (s in dt$Suburb) {
  FirstForecast <- 2025.75
  
  Y  <- log(get_suburb(s))
  
  Time  <- time(Y)
  
  t_est   <- which(Time < FirstForecast)
  
  # We will have a standard 15% (approx 4 years) zone where no break points are allowed.
  # So with the training set being from 2000Q1 to 2025Q3 gives:
  Break_range <- Time[which(Time >= 2004 & Time < 2021.75)]
    
  # M is a matrix for the RSS corresponding to each b
  M <- matrix(nrow = length(Break_range), ncol = 2)
  colnames(M) <- c("b", "RSS")
  M[, "b"] <- Break_range
  
  for (b in Break_range){
    TB_b <- trend_break(b, Time[t_est])
    X <- cbind(Time[t_est], TB_b)
    
    eq1 <- Arima(Y[t_est], order=c(0,0,0), xreg=X)
    
    # Store RSS in appropriate entry of M
    M[which(M[, "b"] == b), "RSS"] <-  sum(eq1$residuals^2)
  }
  b_best  <- M[which.min(M[, "RSS"]), "b"]
  
  trend_breaks[[s]] <- list(
    b_best  = b_best
  )
}

Fixing The Stochastic Part

Finally, lets estimate our models with access to the entire data set, using a very similar process as in Part B.

RNGkind("L'Ecuyer-CMRG")   # reproducible random streams across cores
set.seed(123)

fit_suburb_future <- function(s){
# Loop over every suburb (row) within our dataset.
  pmax <- 9 # Max AR lag order
  qmax <- 9 # Max MA lag order
  FirstForecast <- 2025.75
  
  Y  <- log(get_suburb(s))

  
  Time   <- as.numeric(time(Y))
  t_est  <- which(Time < FirstForecast)

  b   <- trend_breaks[[s]]$b_best
  TBt <- 1 * (Time > b) * (Time-b)
  
  hmax <- 24
  
  # Storage for Ljung-Box p-values and AICc
  LBp <- matrix(nrow=pmax+1, ncol=qmax+1)
  rownames(LBp) <- paste0("p=", 0:pmax)
  colnames(LBp) <- paste0("q=", 0:qmax)
  AICc <- LBp
  
  nd <- adf_test(Y[t_est], cbind(Time[t_est], TBt[t_est]))
  
  # Build regressors for the future quarters (Dec 2025 onwards)
  Time_future <- max(Time) + (1:hmax) / 4
  TB_future   <- 1 * (Time_future > b) * (Time_future - b)
  
  if (nd == 0){
    X_future <- cbind(Time = Time_future, TBt = TB_future)
  } else {
    X_future <- cbind(TBt = TB_future)
  }
  
  if (nd == 1){
    # Drops first training quarter, so results line up with diff(Y[t_est])
    # which starts at the second quarter. 
    DU <- 1 * (Time[t_est][-1] > b)  
    nd <- nd + adf_test(diff(Y[t_est]), cbind(DU))
  }
  
  if (nd == 0){
    X <- cbind(Time, TBt)
    drift <- FALSE
  } else if (nd == 1){
    X <- cbind(TBt)
    drift <- TRUE      # drift = constant growth rate, replaces Time
  } else {
    X <- cbind(TBt)
    drift <- FALSE     # trend annihilated at d = 2
  }

  
  models <- list()
  
  for (p in 0:pmax){
    for (q in 0:qmax){
      
      eq <- fit_arima(Y[t_est], c(p, nd, q), X[t_est, , drop = FALSE], drift)
      if (is.null(eq)) next
    
      AICc[p+1, q+1] <- eq$aicc
      LBp[p+1,q+1] <- Box.test(eq$residuals, 
                             lag = max(8, p + q + 4), 
                             type = "Ljung-Box", 
                             fitdf = p + q)$p.value
      models[[paste(p, q)]] <- eq
    }
  }
  # Best model: lowest AICc among those passing Ljung-Box
  AICc_ok <- AICc
  # Blank any AICc values matching the matrix locations where
  # LBp <= 0.05 
  AICc_ok[LBp <= 0.05 | is.na(LBp)] <- NA 
  
  if (all(is.na(AICc_ok))) {
    cat("No model passed Ljung-Box for:", s, "\n")
    next
  }
  
  best <- which(AICc_ok == min(AICc_ok, na.rm = TRUE), arr.ind = TRUE)
  p_best <- best[1, 1] - 1
  q_best <- best[1, 2] - 1
  model  <- models[[paste(p_best, q_best)]]
  
  # Forecast future quarters, with intervals, and convert back to dollars
  fc <- forecast(model, xreg = X_future, h = hmax)
  forecasts <- ts(exp(as.numeric(fc$mean)),       start = c(2025, 4), frequency = 4)
  
  # 95% Interval assuming normality
  lower95   <- ts(exp(as.numeric(fc$lower[, 2])), start = c(2025, 4), frequency = 4)
  upper95   <- ts(exp(as.numeric(fc$upper[, 2])), start = c(2025, 4), frequency = 4)
 
  
  return(list(
   suburb      = s,
    Y           = Y,
    Y_train     = Y[t_est],
    model       = model,
    trend_break = b,
    nd          = nd,
    p           = p_best,
    q           = q_best, 
    AICc        = AICc,
    forecasts   = forecasts,
    lower95     = lower95,
    upper95     = upper95
  ))
  
}

top10_growth <- function(start, end, period, start_label, end_label) {
  g  <- end / start - 1
  t10 <- sort(g, decreasing = TRUE)[1:10]
  nm <- names(t10)
  
  tab <- data.frame(
    Period   = period,
    Rank     = 1:10,
    Suburb   = nm,
    Start    = start[nm],
    End      = end[nm],
    Growth   = 100 * t10,
    row.names = NULL
  )
  
  print(kable(tab[, -1], digits = 1,
              col.names = c("Rank", "Suburb", paste(start_label, "(\\$/week)"),
                            paste(end_label, "(\\$/week)"), "Growth (%)"),
              caption = paste("Top 10 suburbs by rent growth,", period)))
  tab
}
